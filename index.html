Quick setup

to first batch.

Run the tool on your computer. This website doesn’t access your Canvas account.

Save the instructions ↓

Download and open the folder

Download the toolkit above and unzip it. Move the extracted canvas-video-downloader folder to your Desktop, then open Terminal:

cd ~/Desktop/canvas-video-downloader

If you put it somewhere else, use that folder’s path instead.

Install once

Run these commands in Terminal:

python3 -m venv .video-venv
source .video-venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install chromium

In each new Terminal session, return to this folder and run source .video-venv/bin/activate again.

Choose where to start

Copy a lesson’s Canvas page URL. Replace the placeholder below with that URL, keeping the quotation marks:

python canvas_videos.py --start "STARTING_LESSON_URL_HERE" --count 8 --workers 3

--count 8 includes the starting lesson and the next seven course items. Readings and quizzes count toward the total, so you may get fewer than eight videos.

Sign in and download

Complete PennKey login and MFA in the browser window that opens. Wait until the lesson video appears, then return to Terminal and press Enter.

Videos are saved in a canvas_videos folder inside your current Terminal directory. Items without an enabled Panopto Download button are skipped. Rerun the command to retry failures; completed downloads are skipped automatically.

Choose specific lessons or change the output folder

Create a file called lessons.txt with one lesson URL per line, then run:

python canvas_videos.py --urls lessons.txt --workers 3

Add --out /path/to/folder to choose a destination, or --dry-run to list the batch without downloading. See every option with python canvas_videos.py --help.

Compatibility and current testing status

This version supports course 1942808 on canvas.upenn.edu and its Panopto player. It requires an enabled Download button and a separate browser sign-in each run. Interactive quizzes are not included in downloaded videos.

The starting lesson’s download control was inspected while signed in. Local syntax and command-line checks passed. A complete download run through the script has not yet been verified.
